# OpenH3M beta 0.8

The first binary release of Open Halo 3 Mythic brings the Halo 3 Mythic multiplayer disc to native Windows x64 through static recompilation.

## Highlights

- Complete 3D Mythic menu backgrounds
- Custom Games and gameplay
- Local split screen for one to four players
- Forge, including player/build mode switching
- Windowed Direct3D 12 presentation
- Live FPS counter in the window title bar
- Major four-player rendering bottleneck fixes

## Setup

Extract the archive, place your legally extracted Halo 3: ODST Multiplayer Disc (Disc 2) files in the included `game` folder, then run `OpenH3M.exe`. The directory must contain `game\default.xex` and `game\maps\`. No launcher script or command-line arguments are required.

Game data is not included. See the repository README for complete instructions and controls.

## Known limitations

- Matchmaking is not supported and never will be supported.
- Xbox LIVE is not supported.
- System Link is currently untested.
- Theater can be entered, but recording and saved-film playback are not fully validated.
