# System Link development

OpenH3M's System Link work lives on `feature/system-link`. Xbox LIVE and Matchmaking are out of
scope. The target is local-network compatibility with OpenH3M peers and, eventually, unmodified
Halo 3 Mythic running on Xbox 360 consoles.

## Privacy boundary

Normal OpenH3M networking does not capture traffic. The console-compatible transport is an
explicit opt-in mode that uses Npcap non-promiscuously with a kernel filter restricted to Xbox
System Link IPv4 broadcasts from `0.0.0.1` on UDP 3074. It does not use router access, port
mirroring, or traffic forwarding. Packet payloads are processed in memory but are never written to
the log or persisted; local IPv4, port, packet-size, authentication, and compatibility metadata can
appear in local log files.

## Current host layer

- Selects an active, non-loopback Windows IPv4 adapter.
- Supplies Halo with that adapter's IPv4 and Ethernet identity instead of ReXGlue's loopback and
  placeholder MAC address.
- Reports an active Ethernet link to the guest.
- Logs XNet startup, address-conversion results, socket creation, binds, and sampled UDP send/receive
  metadata.
- Implements the Xbox Secure Network Library broadcast wrapper used by retail Xbox 360 System
  Link discovery. It derives the title-specific authentication, 3DES, and IV keys from Halo's XEX
  LAN key, authenticates and decrypts console broadcasts into Halo's guest UDP sockets, and wraps
  Halo-generated broadcasts for the console.
- Rejects modified packets, wrong LAN keys, other title IDs, and incompatible Halo title versions
  before delivering traffic to the game.
- Installs at Halo's import addresses after the guest module is loaded, keeping the changes local to
  OpenH3M rather than forking ReXGlue.

Use `--open_h3m_system_link=false` to disable the compatibility layer or
`--open_h3m_system_link_log=false` to disable its metadata logging.

## Validation status

The authenticated broadcast codec and Ethernet frame transport have offline unit coverage. A real
Xbox 360 still needs to confirm that a Halo-generated host advertisement appears in Find Game and
that its finder query is delivered to OpenH3M. Passing discovery will expose the next boundary:
secure unicast address mapping, connection state, QoS, and session traffic. Console testing uses
traffic generated by the game itself and bounded metadata logs; it does not require access to
unrelated home-network traffic.
