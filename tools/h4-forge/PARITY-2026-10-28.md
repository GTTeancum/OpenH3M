## Original glow material sources verified (2026-10-28)

`decode_marker_bitmaps.py` now decodes all five source base images. The gradient
is a linear BC1 texture whose mip 0 is already in the packed tail (256x1, block
row 4, byte offset 2048 within the resource). Decoding its first raw bytes as
mip 0 produced a visibly broken gradient and was rejected. The corrected
red/orange gradient and both 128x128 plasma images were inspected. The plasma
base mips come from optional pages 1279/1280; the required page starts with
smaller mips. The corrected gradient matches Pillow's independent BC1 decoder
byte for byte. The previously verified ring/rays pixel hashes are unchanged.

`extract_marker_shaders.py` resolves materials 16 (`particle_base`) and 331
(`particle_palettized_plasma`) through their schema-validated `mtsb` bank 17.
It reads runtime shader headers using Assembly's Halo4 shader layouts, separates
constant data from microcode, and extracts six original programs (two vertex
types and one pixel shader per material). The offline `h4_forge_shader_disasm`
target builds ReXGlue's existing decoder and disassembles all six without a GPU
device, window or game. `verify_marker_assets.py` compares the microcode directly
with the retail cache, validates all five decoded texture hashes and checks the
gradient using the independent decoder. All checks pass. The 47 integrated
original H4 function bodies also still match ReXGlue output exactly.

The original plasma pixel shader samples noise maps A/B, takes their absolute
difference, combines that with ring alpha/particle alpha/depth fading, and uses
the result to sample the palette. Material constants set A's UV slide to
(0.5,0.5), B's to (-0.5,-0.5), palette multiplier to 1, and depth-fade range to
0.5. Both materials disable constant screen size. Particle definitions select
camera-facing billboards and contain original age-driven color/intensity/alpha
functions. These facts rule out treating fixed-pixel cyan/yellow circles as
finished H4 appearance. The full function interpretation, lifetime/size inputs,
HDR blending and renderer integration remain required; no live glow pass is
claimed from extraction or disassembly.

Private data and disassembly stay in `isolated/marker-bitmaps` and
`isolated/marker-shaders`. No production renderer or installed binary changed
in this material-extraction step. Primary schema references:
[Assembly shader bank](https://github.com/XboxChaos/Assembly/blob/dev/src/Assembly/Plugins/Halo4/mtsb.xml),
[Assembly runtime shader layouts](https://github.com/XboxChaos/Assembly/blob/dev/src/Blamite/Formats/Halo4/Layouts/H4_Layouts_Shaders.xml),
[TagTool Gen4 effect definitions](https://github.com/TheGuardians/TagTool/blob/master/TagTool/Tags/Definitions/Gen4/Effect.cs).
