# Small surviving retail attachment audit

These asset-free Python files were independently reconstructed during recovery on 2026-11-18. They are **not** the lost Reach converter. See [the Codex closeout](../../docs/conversion-handoff/README.md).

`native_attach_audit.py` reads original H3 retail caches without modifying them. `placement_contract.py` validates a narrow automatic-attachment mapping and can propose an exact-hash E25 delta without writing it; the E25 map itself was not recovered. `test_placement_contract.py` records small contract tests. The summary is historical recovery evidence, not a new closeout run.

Recovery reported 24 real stock controls, 2,068 eligible Slayer spawn markers, automatic policy, zero manual override and compiled mask 1. Full scenario creation, BSP point assignment, team/mode semantics, resources, finalization and runtime remain outside these utilities. No game assets are included.
